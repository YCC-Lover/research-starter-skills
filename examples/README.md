# 科研与论文写作使用示例

[返回首页](../README.md) · [下载最新技能包](https://github.com/YCC-Lover/research-starter-skills/releases/latest)

这里有 10 个可以按自己的材料改写的任务提示词，覆盖总入口和六个小 skill。先安装全部七个技能，再在 Codex 中附上文件或提供可读取的项目路径。提示词中的材料名称是示例描述，不代表仓库附带真实论文或实验数据。

以下是任务设计与交付目标，不是实际模型运行记录或效果保证。检索、文件解析、作图和文档导出依赖当前环境的工具；工具不可用时应明确说明，不声称已完成。尤其不能仅凭这些技能直接解析 Origin 的 `.opju` 项目：需可用的 Origin 接口，或先导出可读取的数据。

## 1. 材料零散，不知道先写什么

**准备材料：** 研究笔记、已有文献、真实结果及写作要求。有多少提供多少，不需要先整理成完稿。

```text
使用 $research-starter-paper，帮我整理这批研究材料。
目标：形成中文学位论文章节的写作计划，现在先不写全文。
请先读取我提供的文件，区分已完成结果、文献依据、解释假设和计划。
输出：材料盘点、核心研究问题、主张与证据对应表、章节提纲、优先下一步。
只追问会改变研究结论或章节安排的重要缺项。
没有证据的内容标为待补，不生成虚构结果。
```

**交付重点：** 明确哪些段落可以开始写，哪些还缺证据；不把写作计划冒充已完成稿件。

## 2. 方向太宽，难形成研究问题

**准备材料：** 研究方向、代表论文、已有实验条件与资源限制。

```text
使用 $rsk-research-design，帮我把“聚合物溶胀与热行为”细化为研究问题。
请以所附代表论文和现有设备清单为依据，比较三个候选问题。
每个问题写出：研究对象、具体缺口、最近邻工作、可检验假设、最小验证和失败条件。
优先建议一个能在现有资源下推进的问题，并解释选择依据。
把已有认识、你的推断和需要验证的内容分开。
未检索核验的新颖性不能称为“首次”；尚未做的实验只能写成计划。
```

**交付重点：** 一个可执行的研究卡，而不是把宽泛方向换成更华丽的题目。

## 3. 读完论文，仍说不清其价值

**准备材料：** 有权使用的论文 PDF，以及你想解决的问题。

```text
使用 $rsk-literature，围绕我的研究问题阅读这篇论文。
请形成阅读卡：具体问题、核心设计、假设、实验条件、支持的结论、局限和我的追问。
关键判断注明章节、页码或图表定位。
区分作者主张、数据真正支持的内容，以及你的推断。
最后说明它与我的问题有什么关系，哪些做法可借鉴，哪些条件不能直接照搬。
若文件或部分正文无法读取，说明实际阅读范围，不把摘要当作全文。
```

**交付重点：** 能定位、能讨论的阅读卡，不只是重述摘要。

## 4. 需要文献，但怕引用不可靠

**准备材料：** 待支持的具体句子、种子文献、时间范围和已有 BibTeX。

```text
使用 $rsk-literature，为我的引言主张查找和核验文献。
待支持主张、种子论文和时间范围见附件。
请记录检索式、渠道、日期与筛选理由，并建立“主张 -> 文献 -> 支持范围”表。
区分搜索线索、元数据已核验和全文已读，不把相关题名当作支持证据。
保留现有 citation key；新条目的作者、年份、DOI 和出版状态必须可追溯。
无法核实的项目标为待核验；检索工具不可用时只给检索计划，不声称已检索。
```

**交付重点：** 同时回答“这篇文献是否真实”和“它是否支持这句话”。

## 5. 引言像文献堆砌

**准备材料：** 现有引言、引用列表、方法与结果概述。

```text
使用 $rsk-paper-writing，修改我提供的引言。
先检查“重要问题 -> 既有路线 -> 具体缺口 -> 本文回应 -> 支持证据”是否连贯。
再给出修改稿，保留研究对象、现有引用、数值和学科术语。
贡献表述必须与我提供的方法和结果对应，不夸大新颖性或机制证据。
证据不足之处标为 [待补：具体信息]，并列出最少必要的补充材料。
只处理引言及必要上下文，不重写其他章节。
```

**交付重点：** 有问题意识的论证顺序，以及可以核对的实质修改说明。

## 6. 摘要空泛或结论夸大

**准备材料：** 已确认的方法、结果、局限与摘要要求。

```text
使用 $rsk-paper-writing，根据附件中的真实方法和结果起草英文摘要。
按我提供的目标载体格式组织背景、问题、方法、主要结果和适用边界。
不得补写附件没有的数字、统计显著性、优越性或因果机制。
同时给出摘要核心主张与证据的对应表，标出尚不适合写入摘要的结论。
若关键条件缺失，明确标注待补，并给出不依赖该缺项的保守表述。
```

**交付重点：** 摘要与正文证据一致，而不是仅让措辞更强。

## 7. TG/DTG 图有了，分析难落笔

**准备材料：** 可读取的原始或导出数据、已有图、样品对应关系、测试条件和数据处理记录。若只有 `.opju`，先确认可用接口或完成数据导出。

```text
使用 $rsk-experiments-figures，检查不同处理条件下的 TG/DTG 图并协助撰写分析。
数据、样品标签、测试条件及已有处理记录见附件。
先核对温度与质量单位、归一化方式、样品对应关系、导数和平滑设置。
关键测试条件缺失时明确指出，不默认各组可直接比较。
根据真实数据撰写中文结果段落和图注，区分观察、解释假设和未验证机制。
没有重复实验或适当检验时，不补画误差线，也不声称统计显著。
需要创建图表时使用可用科学作图工具，并交付数据来源与必要脚本；工具不足则说明限制。
```

**交付重点：** 数据处理可追溯，图注说明比较条件，结论强度与证据一致。这是材料表征任务模板，不包含真实测试结果。

## 8. 审稿意见多，回复缺少条理

**准备材料：** 真实审稿意见、原稿、修改稿及已完成工作的记录。

```text
使用 $rsk-rebuttal，根据真实审稿意见与附件稿件起草逐条回复。
保留 reviewer 和意见 ID，分类整理误解、错误、证据不足及表述问题。
每条回复给出简短回应、具体证据、修改定位和完成状态。
尚未做的实验只能列为建议或计划，不能写成“已新增”。
没有稿件定位时明确待补，不编造页码或行号。
交付回复稿，以及“意见 ID | 要点 | 证据定位 | 修改定位 | 状态”覆盖表。
不要自动提交回复或联系编辑。
```

**交付重点：** 每条意见有去向，每个“已修改”都能找到真实依据。

## 9. 组会不知道怎么讲重点

**准备材料：** 近期真实进展、异常或失败记录、待决策问题与听众情况。

```text
使用 $rsk-research-workflow，依据附件进展准备一份十分钟组会提纲。
围绕研究问题组织：本次目标、关键证据、异常与局限、需要讨论的决策、下一步。
每页只保留一个主要信息，并指出应放哪张已有图或哪条记录。
给出三个值得讨论的问题，不把计划中的工作写成完成的成果。
目前只交付提纲和讲述要点，不生成或发送幻灯片。
```

**交付重点：** 听众能理解进展、证据与需要作出的判断，而不是只看到工作量。

## 10. 第一次参会，准备不充分

**准备材料：** 真实日程、研究简介、希望交流的主题和实际时间限制。

```text
使用 $rsk-research-workflow，根据附件会议日程与我的研究简介准备参会方案。
按研究相关性和时间冲突筛选报告，写明选择理由。
准备一个简短研究介绍、三个可调整的提问，以及会后跟进草稿。
尚未发生的交流标为计划，不虚构认识的研究者或合作关系。
涉及现行会议安排时核对官方信息；无法核对的内容标为待确认。
只生成草稿，不替我报名、联系他人或发送邮件。
```

**交付重点：** 可调整的参会计划与交流准备，不把历史经验当作当前会议规则。

## 一个改写示意：证据不足时怎么写

以下仅演示表达边界，不是真实实验结论或模型实测输出。

**假想原句：**

> 处理显著提高了样品热稳定性，并证明了其作用机制。

**在缺少重复实验、检验及独立机制证据时，可改为：**

> 在所提供的测试条件下，处理组与对照组的热行为存在差异；差异的稳定性及其原因仍需进一步验证。[待补：重复实验、比较指标及机制证据]

是否存在差异本身也必须由真实数据确认。若只有研究计划，应改写为“拟比较处理组与对照组的热行为”，不能写成观察结果。

## 怎样写出自己的任务提示词

```text
使用 $[技能名称]，完成 [本次具体任务]。
材料：[已附文件或可读取的项目路径]。
目标：[语言、章节、听众、投稿要求或交付格式]。
保留：[数值、单位、引用、术语、现有结构等]。
输出：[本次需要的稿件、表格、提纲或文件]。
边界：只处理本次范围；缺失证据明确标注，不虚构事实或完成状态。
```

将 `$[技能名称]` 替换成索引中的真实名称。不确定时先用 `$research-starter-paper`。输出后仍需作者核对数据、引文、分析与目标规范。

公开反馈请只使用脱敏或有权公开的材料，不上传未发表论文、实验数据或个人敏感信息。
