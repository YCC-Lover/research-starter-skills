# 七个可核对的完整任务包

[首页](../../README.md) · [任务提示词](../README.md) · [行为评测](../../evals/README.md)

所有输入均为本项目自行编写的合成教学材料。论文摘录、样品、数值、机构规则和意见都不是实际研究或真实发表记录；引用键不能用于论文。任务包用于练习和核对，不承诺统一输出或科研成效。

| 任务 | 输入 | 对应 skill | 交付与核对 |
| --- | --- | --- | --- |
| 零散材料的任务简报 | [材料](brief.md) | research-starter-paper | 目标、实际可用材料、可交付范围，不声称读过未提供文件 |
| 候选课题选择 | [材料](decision.md) | rsk-research-design | 条件性建议、资源依赖、能改变建议的新信息 |
| 多文献综合 | [三份摘录](literature.md) | rsk-literature | 主张-证据矩阵及限定范围的综合，不平均不可比数值 |
| 学位论文章节修改 | [章节与结果](thesis.md) | rsk-paper-writing | 指定章节修改稿、跨章冲突、实质变更与待确认项 |
| TG/DTG 检查 | [CSV](thermal.csv)、[元数据](thermal.json) | rsk-experiments-figures | 可追溯计算、条件差异与分析边界 |
| 返修联动 | [意见、回复与稿件](revision.md) | rsk-rebuttal | 拆分“已答复”和“实际已修改”，不复制旧页码 |
| 开题问答演练 | [研究介绍](rehearsal.md) | rsk-research-workflow | 依请求一次一个问题；反馈针对用户原句 |

## 使用方式

安装七个技能后，把对应输入附到新对话，使用 [提示词](prompts.md)。脚本安装目录不需要存放这些输入。工具不足时可只做材料范围内的文字检查；不能把计划写成已运行。

先尝试指出输入里的一个风险，再让 skill 解释或修改。核对标准不是措辞相同，而是来源、数字、比较条件、完成状态和任务范围正确。所有纠错点见 [自查](self-check.md)；另有 [实际模型答复](../../evals/runs/2026-10-20/OUTPUTS.md) 与 [逐项报告](../../evals/runs/2026-10-20/REPORT.md)，不把自查示意冒充实际输出。

[交付结构示意](walkthrough.md)由维护者编写，帮助理解材料如何对应判断，不是独立模型实测。热分析另有 [确定性工具实际运行记录](thermal-check.json)，可核对算法、输入校验值与输出；这同样不能证明整套模型流程的质量。

热分析脚本默认只读；需要本次明确允许计算且环境有 NumPy 时使用 `--derive`。不自动安装依赖，不更改 CSV，不作统计或机理判断。实际生成文件必须按用户环境规则指定工作目录。
