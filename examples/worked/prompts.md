# 对应任务提示词

以下提示词配合 [任务包](README.md) 的指定输入使用，不假设当前目录或本机路径。每次只选一个任务。

```text
使用 $research-starter-paper。请根据 brief.md 整理本次任务简报及最小下一步，不写论文或修改文件。
```

```text
使用 $rsk-research-design。根据 decision.md 比较两个方案，给出有条件的优先建议、关键风险、最小验证和能改变建议的新信息。
```

```text
使用 $rsk-literature。根据 literature.md 的三份教学摘录制作主张-证据矩阵，核对草稿主张，并给限定范围的综合段落。不联网，不补造正文。
```

```text
使用 $rsk-paper-writing。根据 thesis.md 仅修改第三章讨论段，给实质修改说明与跨章待核对清单，不改其他章节。
```

```text
使用 $rsk-experiments-figures。根据 thermal.csv 与 thermal.json 检查条件，允许本次用随技能提供的工具计算 -d(mass%)/dT；不平滑、不改原数据。给数据检查、可比性判断及简短观察，不作机制或统计结论。工具不可用时说明尚未计算。
```

```text
使用 $rsk-rebuttal。按 revision.md 核对回复、实际修改与证据，交付回复草稿、联动表和未解决项，不代改原稿或提交。
```

```text
使用 $rsk-research-workflow。按 rehearsal.md 先开始一轮开题演练，一次只问一个问题，等待我回答。
```
