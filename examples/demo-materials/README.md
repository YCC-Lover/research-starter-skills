# 随包教学材料

这些材料全部自行编写，不包含用户数据、原教程正文或真实实验结论。可离线读取，不需要先准备私有论文。

1. 将 [research-notes.md](research-notes.md) 与 [thermal-demo.csv](thermal-demo.csv) 交给 $rsk-experiments-figures，请求图注、描述性观察及证据缺口。曲线是**合成教学数据，不是实测结果**。
2. 将 [reviewer-comments.md](reviewer-comments.md) 交给 $rsk-rebuttal，请求逐条回复与覆盖表。核对 R1.2 是否仍为未完成，而不是变成“已新增实验”。
3. 将前两份材料交给 $research-starter-paper，请求下一步计划。计划必须区别教学练习与真实科研验证。

可直接提出：

~~~text
使用 $rsk-experiments-figures，读取本目录的 research-notes.md 和 thermal-demo.csv。
只把它们当作合成教学材料。输出图注、可见观察和真实研究迁移时的待补清单。
不声明统计显著、材料性能提升或已证实机制，也不假称有真实实验。
~~~
