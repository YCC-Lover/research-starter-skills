# 可复制的首次任务

安装全部七个技能后，在 Codex 中打开本仓库，或者附上 introduction-draft.md 与 evidence.md。不要只给文件名却不提供可访问路径。

~~~text
使用 $rsk-paper-writing，只修改这份教学引言。
请读取 introduction-draft.md 和 evidence.md；附在对话中时以附件为准，
打开仓库时文件位于 examples/first-run/。
输出修改稿和简短修改说明，不写其他章节。
保留两个 citation key；根据材料纠正数值措辞，标注缺失证据与引用状态。
~~~

想学习时可加：“先解释哪些句子超出证据，再让我试改一句，随后给反馈。”只想检查时改为“先列问题，不重写或修改文件”。
