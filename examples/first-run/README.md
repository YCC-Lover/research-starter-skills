## 输入与操作

1. 按 [安装指南](../../docs/INSTALLATION.md) 安装七个技能，在后续 Codex 对话中使用。
2. 打开本仓库目录，或附上 [草稿](introduction-draft.md) 和 [证据](evidence.md)。这些输入不需要复制进技能安装目录。
3. 使用 [任务提示词](prompt.md)。没有文件访问权限时直接附文件，不要假设“本目录”就是当前聊天的工作目录。
4. 对照下面的清单检查输出。学习时也可以先自己改一句，再让 skill 解释区别。

## 自查

- 8.0% 与 6.0% 不变，绝对变化是降低 2 个百分点；相对降低 25%，不能混为降低 2%。
- 不再声称所有场景优越、统计显著或机制已证实。
- 两个 citation key 保留，并明确是未核验的教学占位符。
- 只修改引言，不捏造完整方法、文献、重复实验或额外结果。
- 阅读定位指向 E1、E2、E3；待补内容具体且不伪装为完成。

可查看 [实际运行输出](actual-output.md)及 [行为评测](../../evals/REPORT.md)。单次输出不是固定标准答案；不同模型或工具可能不同，应以材料和检查点判断。
