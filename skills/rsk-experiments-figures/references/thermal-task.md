# TG/DTG 任务包

本仓库独立补充，不是仪器操作规程或机理判定数据库。先确定任务是检查、描述、计算还是作图；只检查不自动计算导数、平滑或改数据。

## 最小输入

可读数据、样品与列对应、温度与质量单位、归一化依据、气氛/流量、升温速率、起止温区、样品质量及重复类型。未知项保留未知。专有项目需实际可用接口或导出，不能把 `.opju` 文件名当作读取成功。

可用 [元数据模板](../assets/thermal-metadata.json) 随 CSV 交接；其空值不是默认仪器设置。确认同一样品重复与独立样品不同。DTG 需写清是 dm/dT、-dm/dT、dm/dt 还是其他定义和单位。

## 只读辅助工具

`scripts/check_thermal_data.py` 位于本 skill 内。它读取 UTF-8 CSV 和可选元数据，只向标准输出报告，不写文件、不联网、不修改输入。默认检查有限数值、列名、温度严格递增、列长度、终点定义与比较条件；遇到坏行失败，不偷偷删行、重排或插值修补。

标准 CSV 的温度列为 `temperature_C`、质量列以 `_pct` 结尾。使用其他列名时须在元数据明确列名和单位；不把没有单位的质量数字自动当作百分比。

```text
python <本skill目录>/scripts/check_thermal_data.py <数据.csv> --metadata <元数据.json>
```

需要计算且已获允许时才加 `--derive`。该选项依赖环境已有 NumPy，采用 `numpy.gradient(mass, temperature, edge_order=1)` 计算 **-d(mass%)/dT，单位 %/C**；不平滑。依赖缺少时停止并说明，不自动安装。不要把采样网格上的最大导数称为经仪器认证的峰温；端点差分、网格与噪声会影响结果。

脚本输出是数据质量与描述性计算，不判断统计显著性、热稳定性优劣或化学机制。末端质量仅对应实际末端温度，不自动命名为灰分；百分质量也不能在缺少定义时解释为某组分含量。

## 交付与核对

按请求提供比较条件表、描述性观察、图注、处理记录与仍缺证据。保留原始文件 SHA-256、样品/列、算法、参数和派生结果位置，图注与计算采用同一导数定义。若条件不同或未知，先写不可直接归因，不为完成段落补造一致条件。

可选流程：输入检查 -> 获授权的计算 -> 图表/段落 -> 逐项回到数据核对。它不是所有任务的强制步骤。实际机制解释还需用户提供的其他表征和对照，生成图像不能替代实测数据。

算法依据：[NumPy gradient 文档](https://numpy.org/doc/stable/reference/generated/numpy.gradient.html)。这只是数值工具来源，不是热分析标准。
