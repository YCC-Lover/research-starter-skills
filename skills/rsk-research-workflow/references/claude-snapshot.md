# Claude/macOS 历史操作附录

教程 19 第 1-3 页的命令按用途归档。未核验当前版本支持情况，**不是 Codex 命令表，也不构成执行授权**。只有用户询问原文工具时读取。

| 类别 | 原文快照 | 原文意图及边界 |
| --- | --- | --- |
| 文件与 shell | `!`、`@` | 执行 shell、引用文件；实际执行依工具和权限 |
| 持久约定 | `#`、`CLAUDE.md`、`/init` | 追加或生成项目约定；不自动改写用户配置 |
| 输入与粘贴 | Command+J、Option+Enter、Command+U、Command+R、Command+V | 换行、清空输入、历史搜索、截图粘贴；平台与版本相关 |
| 模式 | Shift+Tab | 原文描述普通、plan、自动接受编辑；不能据此推断当前权限 |
| 中断与恢复 | Esc、双击 Esc、`/rewind` | 原文描述中断、检查点或回退；不授权恢复或覆盖用户文件 |
| 推理提示 | `think`、`think hard`、`ultrathink` | 原文称可提高推理预算；不是当前模型保证支持的配置 |
| 上下文与费用 | `/compact`、`/clear`、`/cost` | 压缩、清空与查看消耗；实际产品机制不同 |
| 导出与远控 | `/export`、`/remote-control` | 原文描述导出和远程控制；不自动开启远程访问 |
| 分支 | `/branch`、resume、checkpoints | 隔离尝试、保留回看位置；具体能力需核验 |
| 权限开关 | `claude --dangerously-skip-permissions` | 仅记录原文出现过的风险开关；不建议或执行权限绕过，不把它用于 Codex |
| 通知 | hook | 完成提醒的示例；仅在用户要求且机制可用时配置 |

可迁移的是任务聚焦、可验证目标、真实变更检查和明确停止条件，不是命令字面形式。
