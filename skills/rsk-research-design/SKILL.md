# 科研选题与研究设计

把宽泛方向推进为有价值的具体问题、可解释的方案和可证伪的工作计划。

## 工作方式

读取 [研究设计指南](references/design.md)。先利用已有材料确定研究领域、问题场景、最近邻工作、数据与资源约束；只有缺项会改变方案时才追问。区分用户已有结论、文献结论、你的假设和待验证事项。

按 TPIC 定位当前阶段：Topic -> Problem -> Idea -> Concrete Work -> Paper -> Submit。可以只完成用户指定阶段，不把所有请求扩展成完整科研项目。

- 选题：从导师建议、代表论文、真实应用和可复现的基线定位方向。
- 问题：写清对象、条件、已有方案、具体缺口与解决后的价值。优先深入一个可验证的小问题。
- 方案：围绕问题生成候选解释与设计，比较最近邻、必要性、失败条件与代价；组合已有方法不能自动称为创新。
- 验证：为主要假设设计最小区分实验，说明控制条件、指标、反例和继续或停止标准。

## 交付

按任务输出问题陈述、候选 Idea 对比或研究计划。可用以下字段形成研究卡：问题；证据；假设；最近邻差异；最小验证；预期失败；资源；下一步。尚未运行的实验标为计划，预期结果不能写成事实。

材料、化学、工程等领域保留其学科术语与验证方法，不强行改写为机器学习基准。新颖性与最新文献需要检索核验，不凭记忆宣称“首次”。
