# 找论文与读论文

依据教程 02《如何找论文？》和 03《如何读论文？》提炼。

## 六种互补检索渠道

1. 相关领域会议与期刊：关注录用列表和议程，在集中发布时浏览。原文举 ML 的 ICML/NeurIPS/ICLR、NLP 的 ACL/EMNLP/COLM、视觉的 CVPR/ICCV/ECCV、AI 的 AAAI/IJCAI、数据挖掘 KDD，以及 TPAMI/JMLR/TMLR/TKDE/Nature Machine Intelligence。它们是方向线索，不是完整清单、永久层级或论文质量证明。
2. 种子论文：近期综述、经典或代表作、最近邻、基准工作和导师推荐。建立“为什么是种子”的理由。
3. 双向滚雪球：沿 Introduction、Related Work、基线和参考文献向后找，也沿引用该工作的文献向前找。记录论文间关系，不无限扩大范围。
4. 作者与团队：查看 Scholar、DBLP、Semantic Scholar、实验室主页、GitHub、项目页、Hugging Face 与报告。用原文核验转述。
5. 代码、数据和基准生态：查看代码依赖、baseline 表、leaderboard、issue 与 PR，发现实际限制。排行榜排名需要核对设置、提交时间和比较对象。
6. 持续输入：arXiv、Hugging Face Daily Papers、Scholar 提醒以及 AMiner、Bohrium、ChatPaper 和社交分享。二手推送只作为线索。

使用用户已有的 Zotero 等资料库；不要为了检索自动安装多个工具。论文池可记录题名、链接或 DOI、年份、问题、纳入理由、状态与阅读优先级。

## 七步阅读

1. 宏观浏览：摘要、关键图表、工作类型、问题与主要结果；选择值得深读的部分。
2. 定位具体问题：不是只写研究方向，而是对象、条件和想解释或改善的现象。
3. 检查既有解法：问题是否真实，旧方法为何不足？阅读方法前先提出自己的解法，便于主动比较。
4. 理解方法：输入输出、关键假设、核心设计、与自己的想法的差异及局限。必要时追溯不熟悉的概念。
5. 审查实验：数据、指标、基线、预算、公平性、完整性和代码是否支持主张。关键论文可复现，但不能未经运行声称已复现。
6. 扩展关联：追溯相关概念、前驱方法和后续工作，建立关系图，围绕当前问题停止扩张。
7. 反思：形成批判与创造性追问，包括反例、替代解释、适用范围、下一步验证。原文的“约四成阅读、六成以上思考”是强调主动思考的启发，不是强制时间配额。

## 阅读卡

建议记录：问题和价值；最近邻路线；设计与假设；实验条件；主要证据及定位；未被证据支持的说法；优缺点；自己的候选解释；可复现的最小检查。根据短读、精读或复现裁剪字段。

判断方法强弱时问何时、为何，不把一篇论文的实验结论外推到所有数据和任务。读者提出的实验是建议，不是原论文已做工作。
