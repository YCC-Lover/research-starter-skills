# 从研究问题到写作依据

本文件保留旧版 Codex 独立补充，非作者逐字摘要。教程 01-04 正文现已读取；其核心提炼分别见 [研究设计](../../rsk-research-design/SKILL.md) 与 [文献](../../rsk-literature/SKILL.md)。优先使用对应小 skill，以下跨学科补充可按需参考。

## 01 如何做科研

把研究问题写成能够被证据区分的命题：研究对象是什么，改变或比较什么条件，观察什么结果，何种结果会反驳解释。将“提高性能”“研究机理”等宽泛目标转为明确的比较或检验。

接手已有课题时先查看材料，而不是替用户重新选题。用一个研究简报记录问题、已知事实、未知点、可用材料、下一步行动。用户只需写论文时，这一步可以是一段简述。

## 02 如何找论文

检索由研究对象、问题、方法和指标构成。先查近期综述、关键原始研究和最接近的工作，再沿参考文献及被引关系扩展。针对特定结论优先找原始证据，综述用于定位主题。

记录检索词、数据库、日期和纳入理由。普通写作不强行套用系统综述协议；用户要求系统综述时才制定完整纳排标准与筛选记录。

文献表建议包含：题名、作者、年份、来源、DOI/URL、研究问题、样本/数据、方法、主要证据、局限、与本研究的关系。没有读到全文时注明只读到摘要，不能据此总结全文方法或局限。

若本研究比较 WTR 的不同溶胀条件，检索词可从材料名称、预处理方式、TGA/DTG及热行为扩展；这是学科适配示例，不是该仓库作者提供的案例。

## 03 如何读论文

采用问题驱动的阅读深度。初筛查看研究问题、主要图表和结论；确定相关后核对方法、比较设置、结果和限制。重点论文再检查补充材料、公开代码或数据。

每篇提炼一张阅读卡：

| 字段 | 要回答的问题 |
| --- | --- |
| 问题 | 作者要解决什么具体不足？ |
| 贡献 | 相比最接近的工作新增了什么？ |
| 方法 | 核心步骤和成立条件是什么？ |
| 证据 | 哪个实验、图或证明支持哪个主张？ |
| 限制 | 是否存在替代解释或未检验条件？ |
| 用途 | 能支持本稿哪一句话，还是仅提供背景？ |

读不到的信息写“未获得”，不把猜测写进阅读卡。批评一篇论文时区分作者明确报告的缺陷与读者提出的质疑。

## 04 如何想 Idea

从已发现的证据缺口产生候选想法，例如条件变化下方法是否成立、已有解释是否存在混杂、评价指标是否错配、能否建立更有说服力的对照。

对候选想法检查：与最接近工作的差别、可证伪性、所需材料、成本、最小验证实验及失败后的信息价值。先筛选少量值得检验的方向；用户已经确认选题时不替换选题。

将新颖性与价值分开论证。没有检索支持不能写“首次”“唯一”或“从未研究”；可写明具体差异，并标记需要补查的最近工作。

交付研究方案时将完成的证据与拟开展的工作分开，给出能推进决定的下一步，而不是虚构预期结果已发生。
