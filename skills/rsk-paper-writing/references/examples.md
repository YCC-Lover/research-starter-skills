# 原文教学案例索引

案例来自用户导出的教程截图，已作视觉核对。以下为独立概括，不重新分发截图，不把案例数值当作用户数据。论文发表与获奖标签是作者导出时的描述，需要用于事实陈述时另查原始记录。

## 教程 10：摘要案例，第 2 至 4 页

- *Train for the Worst, Plan for the Best: Understanding Token Ordering in Masked Diffusions*：先指出训练顺序带来的复杂度问题，再解释训练与推理设计的不同目标，最后给量化发现。学习问题、设计和结果的对应关系，不借用其数字或获奖标签装饰自己的摘要。
- *Accelerating LLM Inference with Lossless Speculative Decoding Algorithms for Heterogeneous Vocabularies*：以共享词表限制定位问题，用设计解释如何跨词表协作，再以速度结果回答效率问题。任何“无损”与“加速”都需对应准确性和计时条件。
- *LLM-SRBench*：指出记忆既有方程与真实科学发现难以区分的评估缺口，说明基准构成，再总结发现。基准论文也可使用问题-贡献-证据逻辑；应优先给真实模型数量和条件，避免模糊的多个 SOTA 模型表达。
