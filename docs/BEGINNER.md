# 从一句话开始

不必先懂提示词，也不用把所有论文整理成表格。准备手边的一样东西：导师一句话、一份阅读笔记、一段草稿或一个数据导出；没有文件也可以先说方向。

```text
使用 $research-starter-paper。
我刚读研，没有系统学过科研，也不知道该给你什么材料。
导师说先看看【用自己的话写方向】。
带我一步步做出下次组会能用的东西，工作目录是【项目目录】。
```

技能先利用你已经说过的内容，只追问会改变眼前任务的信息。可以回答“不知道”“没有论文”“只有这个文件”，不需要先补齐一份开题报告。

## 每次拿到一点能用的东西

先把方向变成能讨论的问题，再准备一条检索式或一张阅读卡；已有材料时可以直接整理讲稿、分析结果或写一个段落。每次说明当前完成了什么、下一步只需要什么，不要求先学完整套课程。

想先理解方法，可以看 [原教程与学习路径](LEARNING_PATH.md)。要直接推进任务，就把现有材料交给技能。需要练习时再选练习，执行任务不强制先答题。

## 进度由代理保存

引导任务在授权项目中保存 `.research-starter/checkpoints/` 和 `.research-starter/progress.md`：已确认信息、假设、已回答/暂时不知道的问题、真实文件、当前成果与下一步。你不必自己建立模板、编写 JSON 或运行进度命令。

下一次进入同一项目，说：

```text
使用 $research-starter-paper，继续这个项目。
先读取已保存进度和当前文件，今天我只有十分钟。
```

换账号不影响同一磁盘上的项目文件；换机器需要通过你有权使用的方式带上项目。公开技能仓库不包含私人进度。它不会后台监视文件，也不代表换对话后模型凭空记住历史；需要让新对话定位到项目。

原始材料变化或文件缺失时，会提示重新核对；旧计划不会自动变成已完成。只有保存成功才会报告已保存。只读检查、单段润色或你说“不保存”时，不强制建立研究记录。

## 让文字像自己的表达

```text
使用 $rsk-paper-writing。
请把这段话写得自然一些，保持研究含义、引用和数值。
这是我的写作样例：【一两段自己的文字】。
只给最终稿。
```

语气匹配、结构调整与表达复核不会替代证据。数学量词、统计限定、访谈原话和专业术语按实际研究保留，不用同一套句式统一所有学科。

## 材料与隐私

只提供有权分享的内容。访谈、患者、学生和未发表合作材料先脱敏，遵守团队要求；技能不会替你申请伦理批准或自动上传材料。PDF、Word、Origin 等文件的可读程度取决于当前工具，未读部分不会被补成事实。
