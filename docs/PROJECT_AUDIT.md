当前审查对象：v2.0.0 的完整研究工作流整合、Codex 执行适配与既有轻量任务回归。下方保留各版本的处理依据；历史任务结果不作为当前版本的通过证明。

## v2.0.0 进阶研究整合

| 需求 | 交付与核对入口 | 已验证的范围 |
| --- | --- | --- |
| 完整保留模式和角色能力 | 七个原入口、35 模式索引、1,131 个固定版本资源 | 五类工作流的路径、归属、契约和文件字节；不按文件数推导科学效果 |

| 可在本机执行关键检查 | Windows PDF、证据文件、条件绑定、投稿清单、研究分支及活动记录适配 | Python 3.13 的真实文件/CLI 测试；符号链接创建受本机权限限制 |
| 原生隔离筛选 | 新上下文 A/B 输入、实际返回、合并和快照导出 | 三条合成摘要、真实独立上下文、排除复查；不等于真实综述准确率 |
| 实际引用核验 | 稿件字节绑定、正文标记映射、生产元数据客户端与任务缓存 | 一条公开文献：Crossref 匹配，另两服务不可达、非 arXiv 跳过 |
| 实际文件交付 | Pandoc DOCX、XeLaTeX PDF、结构/文本检查与页面预览 | 一份明确标注的合成文档；不推导任意投稿模板兼容性 |

静态依赖检查覆盖 227 个 Python 文件和 152 份 JSON Schema：未发现显式内部导入或
Schema 资源缺失，Python 3.10 语法可解析。该检查不执行动态回调、模型、数据库或
第三方客户端。Windows 研究写入/事务工具按 Python 3.13 验证；安装器与普通文字指导
继续支持 Python 3.10+。

原平台钩子及其权限边界不会在 Codex 自动生效。原生角色按实际上下文和输入范围
记录，不能称为强制沙箱。Windows 文件操作使用调用者控制的目录及继承 ACL；
合作式锁和字节校验不保证抵御任意并发攻击，也不认证断电后的目录持久性。

源项目仍未实现的实时校准结果应用、CLI stance provider 及额外语言包保持原状态。
审稿默认 NOT_CALIBRATED，跨模型任务需实际接通所选接收方，实验方案不冒充真实实验。
代码运行、模型表现、读完文献和科研结论分别核对。

本机完整验收运行 243 项单元测试并成功，7 项因本机不能创建所需符号链接而跳过。
普通与优化模式的包校验、72 条历史/当前记录的完整性检查均通过；当前八题的实际
读取与声明依赖没有变化。另从 Git 索引检出内容完成 1,227 文件的全新安装，并在
独立 Codex 进程中确认七个入口均启用。线上三平台检查以最终发布提交的 Actions 为准。

## v1.3.1 独立验证与发布完整性

在用户允许后执行八题、两组十六次独立任务，覆盖七个入口的新流程与旧引言回归。两组共享相同材料和只读热分析工具，判读时隐藏加载标签；[实际答复与逐项报告](../evals/runs/2026-10-20/REPORT.md)独立保存，不修改手工示意来冒充实测。精确服务端模型、完整工具轨迹和人类专家复核仍不可用，演练只覆盖首问。

匿名下载验收发现 v1.3.0 ZIP 的 CSV 被 Windows 换行转换，导致其原始字节校验值与实际工具记录不一致；数值未变。v1.3.1 固定 CSV 为 LF，增加工具记录与分发源文件校验测试，并检查实际 Git archive。旧 tag 和发布包保留，未覆盖历史资产。本轮初次模型派发的中文传输故障已停止并单独记录，不算科研能力失败或通过。

## 发现与处理

| 问题或改进点 | 处理 | 验证方式 |
| --- | --- | --- |
| 安装器先 resolve 路径，输入目录链接可能被隐藏 | 解析前检查路径祖先、链接与 Windows 重解析点 | 目录链接、备份链接、冲突无部分写入回归测试 |
| 覆盖硬链接文件可能影响其他位置的同一文件 | 在预检阶段拒绝待覆盖硬链接 | 硬链接内容保留与无备份写入测试 |
| 只能安装，难判断当前状态或先预览更新 | 增加 --check 与 --dry-run | 内容修改/缺失检测与完全无写入测试 |
| assert 在 Python 优化模式可能被禁用 | 改为明确失败并输出可定位错误 | 用 python -O 验证故意损坏的覆盖信息仍会失败 |
| 全面禁止 PNG，无法安全公开原创图像 | 只批准有清单、来源、尺寸和 SHA-256 的原创 PNG | 未批准图像及哈希不符回归测试，人工逐图查看 |
| 独立小 skill 的资料/权限边界不够显式 | 每个模块明确不将资料指令当执行许可，说明读取不足 | 逐模块阅读审查，不把静态文本检查冒充模型行为证明 |
| 仅有提示词，没有随包可读材料或图像 | 增加教学 CSV、笔记、虚构意见与三个展示场景 | 实际运行绘图脚本，核对图像和来源 |
| 来源在首页位置不够显眼，贡献入口缺少隐私提醒 | 首页突出原项目、郭兰哲介绍与非官方身份；增加贡献/反馈模板 | 校验相对链接，公开页面与模板检查 |
| 仅验证一个 Python/Linux 环境 | CI 扩展至 Linux Python 3.10、3.13 和 Windows Python 3.13 | 查看当前提交的三个实际 CI job，不以配置文件存在当作通过 |

## 学术内容审查

检查七个入口及各模块参考：保持跨学科语境、任务范围、原教程定位，区分原文概括与整理者补充。重点核对统计显著性、机制、最新文献、引用 key、完成状态、历史资助及参会规则的限定条件。

未把历史教程的句数、段数、SOTA、时长、金额或旧命令升级为当前普遍规则。没有扩大来源“已读”范围，没有修改原导出文件的 SHA-256 与阅读记录，也没有再分发原始 PDF 或图像。

## 剩余边界

- 文件与代码测试不能证明所有模型、学科和稿件上的行为质量；提示词及手工示意与实际模型输出分开标注。本轮没有人类专家复核、真实用户试用或准确率/节省时间等实测收益声明。
- 行为评测仅使用固定合成任务，精确模型版本和完整工具轨迹未返回；模型自报没有副作用不能当作审计通过，对应项目保持无法确认。修正前的失败与重测记录保留。
- 当前来源覆盖只对应固定上游版本的 19 篇教程，不包含致谢链接的整本书，也不表示未来更新已经阅读。
- 本机 Windows 未启用创建符号链接的权限时，对应两项测试会跳过；Linux CI 应实际执行这些测试。不得把本机跳过当作通过证据。
- 安装不是多文件原子事务，复制期间的权限/磁盘错误或并发改动可能留下部分更新。已有备份应保留，用只读检查定位状态，不自动回滚或批量清理。
- 公开示例均无私有原始研究数据；PNG 的来源清单与哈希可核对，不构成对任何未知第三方文件的隐私保证。
- 按维护者选择不增加新许可，下载可读不等于任意转载或商业使用权限。发布范围见 [NOTICE.md](../NOTICE.md)。
