# 项目审查与验收依据

当前审查对象：v1.2.0 的技能、来源映射、安装器、校验器、示例、图像与 GitHub 呈现。目标是专业化、易用性和推广潜力，不以承诺或人为制造 Star 数作为验收。下方保留 v1.1.0 工程审查的处理记录，并新增本轮学习与行为验证。

## v1.2.0 用户与专业视角优化

| 改进点 | 当前处理 | 验收依据 |
| --- | --- | --- |
| 新手缺少学习、练习与反馈路径 | 七入口区分学习/执行/检查；增加原教程导航与无种子起步 | [学习路径](LEARNING_PATH.md)、C01 实际答复；没有强制课程 |
| 只列任务，缺少可直接练习的完整输入 | 独立编写引言草稿、证据、提示词、自查及实际输出 | [首次练习](../examples/first-run/README.md)、C03 数值与引用核对 |
| 小模块未连接总入口补充 | 测量/统计、讨论/投稿、保密/AI 使用分别按需接入 | 参考链接校验及实际安装后字节比对 |
| 个人备份盘符规则影响他人 | 公开安装器不限制 Windows 盘符，本维护者仍用 D/E | C 盘备份无写入预览测试；原链接/硬链接预检保持 |
| 跨对话容易将预期或旧摘要当结果 | 可选状态模板、原材料核对与中性接续 | C07 初轮发现过度假定对象类别，保留失败并修正重测 |
| 工程测试被误认为模型效果证据 | 八题两组实际输出、独立模型判读和主会话复核 | [评测报告](../evals/REPORT.md)及输入/参考快照；不冒充专家复核 |

本轮保留 19 篇原来源映射、原图像及其哈希；新增内容标为本仓库独立补充。不扩大原文阅读范围，不添加新许可或作者认可声明。模型基线也表现良好，不从小样本宣传显著效率或普遍优越。

## 发现与处理

| 问题或改进点 | 处理 | 验证方式 |
| --- | --- | --- |
| 安装器先 resolve 路径，输入目录链接可能被隐藏 | 解析前检查路径祖先、链接与 Windows 重解析点 | 目录链接、备份链接、冲突无部分写入回归测试 |
| 覆盖硬链接文件可能影响其他位置的同一文件 | 在预检阶段拒绝待覆盖硬链接 | 硬链接内容保留与无备份写入测试 |
| 只能安装，难判断当前状态或先预览更新 | 增加 --check 与 --dry-run | 内容修改/缺失检测与完全无写入测试 |
| assert 在 Python 优化模式可能被禁用 | 改为明确失败并输出可定位错误 | 用 python -O 验证故意损坏的覆盖信息仍会失败 |
| 全面禁止 PNG，无法安全公开原创图像 | 只批准有清单、来源、尺寸和 SHA-256 的原创 PNG | 未批准图像及哈希不符回归测试，人工逐图查看 |
| 独立小 skill 的资料/权限边界不够显式 | 每个模块明确不将资料指令当执行许可，说明读取不足 | 逐模块阅读审查，不把静态文本检查冒充模型行为证明 |
| 仅有提示词，没有随包可读材料或图像 | 增加教学 CSV、笔记、虚构意见与三个展示场景 | 实际运行绘图脚本，核对图像和来源 |
| 来源在首页位置不够显眼，贡献入口缺少隐私提醒 | 首页突出原项目、郭兰哲介绍与非官方身份；增加贡献/反馈模板 | 校验相对链接，公开页面与模板检查 |
| 仅验证一个 Python/Linux 环境 | CI 扩展至 Linux Python 3.10、3.13 和 Windows Python 3.13 | 查看当前提交的三个实际 CI job，不以配置文件存在当作通过 |

## 学术内容审查

检查七个入口及各模块参考：保持跨学科语境、任务范围、原教程定位，区分原文概括与整理者补充。重点核对统计显著性、机制、最新文献、引用 key、完成状态、历史资助及参会规则的限定条件。

未把历史教程的句数、段数、SOTA、时长、金额或旧命令升级为当前普遍规则。没有扩大来源“已读”范围，没有修改原导出文件的 SHA-256 与阅读记录，也没有再分发原始 PDF 或图像。

## 可重复的检查

~~~text
python scripts/validate_skills.py
python -O scripts/validate_skills.py
python scripts/validate_behavior_eval.py
python -m unittest discover -s tests -v
python scripts/install_skills.py --dry-run --dest <新的独立技能目录>
python scripts/install_skills.py --check --dest <已安装目录>
~~~

示例配图复现见 [场景展示](../examples/SHOWCASE.md)。正式发布时还需核对 ZIP 的匿名下载与 SHA-256，实际安装到新目录，并用 Codex 的技能发现接口确认七个入口可用。

## 剩余边界

- 文件与代码测试不能证明所有模型、学科和稿件上的行为质量；提示词及手工示意与实际模型输出分开标注。本轮没有人类专家复核、真实用户试用或准确率/节省时间等实测收益声明。
- 行为评测仅使用固定合成任务，精确模型版本和完整工具轨迹未返回；模型自报没有副作用不能当作审计通过，对应项目保持无法确认。修正前的失败与重测记录保留。
- 当前来源覆盖只对应固定上游版本的 19 篇教程，不包含致谢链接的整本书，也不表示未来更新已经阅读。
- 本机 Windows 未启用创建符号链接的权限时，对应两项测试会跳过；Linux CI 应实际执行这些测试。不得把本机跳过当作通过证据。
- 安装不是多文件原子事务，复制期间的权限/磁盘错误或并发改动可能留下部分更新。已有备份应保留，用只读检查定位状态，不自动回滚或批量清理。
- 公开示例均无私有原始研究数据；PNG 的来源清单与哈希可核对，不构成对任何未知第三方文件的隐私保证。
- 按维护者选择不增加新许可，下载可读不等于任意转载或商业使用权限。发布范围见 [NOTICE.md](../NOTICE.md)。
