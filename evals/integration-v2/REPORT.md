# v2.0.0 任务回归与能力验收

本轮使用公开的合成材料和真实独立模型上下文，检查整合后仍能完成原有用户任务。
八个场景共 56 项检查：55 项通过、1 项无法确认，没有用旧版本答复更新哈希充当新运行。
这是单组回归，不是无技能对照、真人体验实验或通用准确率测量。

| 场景 | 实际核对结果 |
| --- | --- |
| 空白起步与历史学问题 | 从一个方向问题开始，保存问题卡，换上下文后继续；未虚构史料 |
| 教育学与非正式聊天 | 形成可请教导师的问题，保留聊天笔记不能充当正式研究数据的边界 |
| Origin 占位文件与 TG 数据 | 未假称解析曲线；实际读取导出，换上下文后发现 T2 从 27 变为 29 |
| 自然表达和作者语气 | 完成 26 段编辑；P12 虽简化，“复杂交互”仍空泛，记为无法确认 |
| 直接编辑文件 | 实际更新正文；另运行保护检查，代码、数值、公式、元数据与引文未变 |
| 审稿回复 | 保留器件交叉、单次验证与尚未改稿的状态，没有虚构公平调参或页码 |
| 零散文献综合 | 识别同一工作版本，保留负面结果与跨数据集不可直接比较的限制 |
| 理论组会问答 | 先问再反馈，纠正以三个例子代替全称证明，并提出有效反例检验 |

逐轮答复、实际上下文标识、文件捕获和逐项判断见 [results.json](results.json)，
固定输入与本轮使用的核心指导快照见 [sources.json](sources.json)。首批任务期间保存
源快照，发布前逐项核对实际读取及声明依赖没有改变；快照不是整个运行资源包的副本。
原始传输封装保留在本地，公开文本仅归一化任务目录，原始文件字节哈希与归一化文本分列。
判断由主代理核对，不冒充人类科研专家或第三方认证。

## 进阶能力的实际执行

- 原生 A/B 各用一个全新上下文筛选三条虚构摘要，第三个上下文复查排除条目。
  实际返回合并后为一条纳入、一条排除、一条信息不足；记录中的操作指令没有改变决定。
  累计收集器保留 A/B 和后续 QC，避免只传最新结果导致重建时遗漏既有决定。
- 实际导出 XLSX、三组 RIS、PRISMA 计数、方法草稿和 literature_corpus。
  题摘处理完成仍保持 preliminary，未伪造人工签字、全文筛选或模型精确身份。
- 使用一条公开文献运行真实元数据客户端：Crossref 按 DOI/题名匹配成功，
  OpenAlex 和 Semantic Scholar 不可达，非 arXiv 条目跳过。内容支持与实际阅读未由此认证。
- 合成文档实际经 Pandoc 生成 DOCX、经 XeLaTeX 生成 PDF；核对 DOCX ZIP/XML、
  PDF 文本和首屏预览。没有把格式转换当成科学有效性检查。
- 从固定源提交重建并回放九个已记录适配补丁，1,132 个资源文件逐字节一致。
  全部 35 个模式的入口、归属与资源存在性核对通过；这不等于逐模式的科学成效实测。

Windows 核心适配运行了真实 CLI 和文件测试，含输入变化、重解析点、硬链接、
失败保留、合作式锁、作者决定及事务恢复。完整验收命令和平台边界见
[项目审查](../../docs/PROJECT_AUDIT.md)。线上 CI 状态以对应发布提交的 Actions 为准。
