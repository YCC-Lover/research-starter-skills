# v2.1.0 科研演示制作验收

本轮使用合成教学材料，不读取私人论文或真实实验数据。科研内容检查、文件结构检查、
独立模型制作和实际 PowerPoint 渲染分别记录，不用资源数量代表科研效果。

| --- | --- | --- |

最终四页未启用网络、图片服务、TTS、动画或视频；导出的转场与对象动画计数均为零。
这些可选能力保留原始资源与按需调用方式，**本轮未验证外部服务或媒体播放**。

## 实际发现与修复

1. 嵌套 PPT 转正文工具最初缺少适配模块导入路径。修复启动器子进程环境，并在没有
   调用者 `PYTHONPATH` 的情况下重新执行，不要求用户手工绕过。
2. 首次 PowerPoint 渲染发现第二页表格数值间距不足。仅修正表格段落对齐、内边距和
   列间分隔，保持数值、列宽及其他三页不变；重新导出并查看实际页面后确认清晰。
3. 模板只换标题时，原封未动的公式预览触发估宽错误。新增绑定源码哈希的保守检查：
   原型、依赖、根属性、全局定义和模块完全一致才标为继承几何；更改文字、公式、
   样式、定义或上下文仍检查。真实新增溢出和全局样式变更负例继续拒绝。
4. 本机 WMI 不响应曾阻塞 Python 平台探测。仅在本次 Python 子进程使用本地标准库
   回退；没有修改系统服务、注册表或全局 Python。

失败日志、旧导出和修复后产物均本地保留，没有刷新旧输出来冒充新测试。
最终产物的哈希与渲染记录见 [实际记录](observations.json)。
