## 历史与当前分开验证

v1.2.0 的来源快照从其真实对应的 Git 提交恢复，并逐项匹配原报告的校验值；原答复和初轮失败记录未改写。当前技能修改不改变这些历史事实，但也不能把历史通过算成新版本通过。

每轮保存实际用例、输入与技能文本快照；校验器先检查历史记录自身一致性，再比较当前轮每题的输入、入口、显式依赖与自报读取参考。仅修改未涉及的 UI 元数据，不会使所有显式调用题自动失效；这不表示已测试自动路由或 UI 行为。

```text
python scripts/validate_behavior_eval.py
python scripts/validate_behavior_eval.py --impact
```

`--impact` 只报告当前用例哪些依赖变化，不运行模型、不刷新历史哈希。重新评测影响到的题时保存新一轮与真实输出；不能把未知副作用、自报读取或引用存在当作已审计的工具执行。`--sources --cases <仓库内用例路径>` 可导出本次源码快照，本身不是行为验证。

## 固定用例

[cases.json](cases.json) 提供八个任务：无种子新手学习、摘要阅读边界、引言数值与引用、不可比热分析条件、未完成审稿实验、资料中夹带的指令，以及跨对话接续、未发生的参会交流。八个任务涉及全部七个入口，但不代表覆盖各模块的所有功能。检查的是事实、任务范围与权限，不按固定措辞匹配答案。

## 对照协议

在相同模型与推理设置下，为每个用例分别开新的独立上下文；两组输入、材料与允许工具范围相同。不加载组不读本项目或其他学术技能；加载组先读指定 SKILL.md 及实际相关参考。不能向执行者提供预期答案、检查表或前一组输出。本次通过 Codex 子代理继承同一主会话设置，未指定不同模型；工具没有返回精确服务端模型版本，不声称已完成跨版本复现。

任务只使用给定材料，不联网、不做真实实验或外部联系；加载组额外只允许读取技能参考。不允许修改输入或仓库，执行者在对话中返回答复；维护者侧记录输出、可获知的运行设置、实际读取文件自报与判读。读取自报不是完整工具审计，工具内部未返回的模型版本不得猜填。

运行需要使用者明确允许启动独立模型任务；不在 CI 中自动调用付费服务，不需要为安装 skills 提供 API key。临时文件使用使用者允许的隔离工作目录，本维护者使用 D/E。

## 判读与复核

逐项对照输入事实检查，状态为通过、不通过或无法确认；失败要给输出原句与理由。本次采用隐藏加载标签的独立模型判读，并由主会话复核原句、数值与输入，**不是人类领域专家评审**。作者或专家可按同一清单再次核对。判读器拼接出的非连续原句不能冒充直接引用，记录中的证据须能在实际答复中定位。

另检查是否有可用的下一步、反馈是否适合用户以及是否过度展开。审查者不能仅凭自报“已验证”打通过；没有完整工具轨迹时，实际上传与文件操作状态保持无法确认。

所有运行记录应保留，不能只展示较好输出。若修复后重跑，要记录修复范围与新一轮，不将选择出的结果当首次运行。单次、小样本、模型判读与已知标签的最终复核无法证明普遍优越、统计提升、节省时间或投稿成功；基线也可能全部通过。实际结果以对应运行记录为准。
