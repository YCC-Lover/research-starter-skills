## 分开核对能力与使用成本

产物是否有用、文件是否真实保存、模型要求用户补什么、是否重复询问、是否需要手工维护记录分别检查。预先固定阶段的任务不能据其轮数宣称降低轮数；真实点击、思考时间和学习收益需要学生参与验证。定量数据与理论命题也不能靠表达检查器判断正确。

## 记录怎样核对

~~~text
python scripts/validate_behavior_eval.py
python scripts/validate_behavior_eval.py --impact
~~~

第一条核对来源快照、已声明运行与重复完整性及判读引文；适用的历史记录还核对双份判读及平均分。第二条列出当前题目哪些输入或技能依赖发生变化。只记录技能运行的任务不会伪造控制组；历史记录原样保留。

历史答复及失败继续保留。v1.3.1的[输入传输故障](runs/2026-10-20/TRANSPORT.md)单列记录，新上下文的正式结果按对应来源保存。工程测试使用确定性的解析器样本，模型实测使用实际运行的完整答复。

## 阅读结果时的上下文

实际执行继承主会话的模型设置；精确后端版本、种子和完整工具轨迹按工具可见范围记录。独立模型判读不是人类满意度测试。全部实验材料均为短的合成材料，不能外推到真实学生、所有学科或复杂私人研究。

新增模型运行由使用者选择并授权，安装和CI验证使用本地脚本。真实任务继续采用自己有权使用的材料、当前来源和项目要求。
