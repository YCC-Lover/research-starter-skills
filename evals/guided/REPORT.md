# 新手引导与表达任务验收

本页保留 v1.5.0 的历史运行。当前版本的重新运行见
[v2.0.0 回归与能力验收](../integration-v2/REPORT.md)。

本轮检验的是新手能否从日常求助开始，拿到当前可用的成果，并在换对话后继续。全部输入为合成练习，不是私人论文、真实参与者材料或真人使用实验。固定规则见 [协议](PROTOCOL.md)，逐轮正文、保存文件与进度读回见 [实际输出](OUTPUTS.md)。

## 能看到的具体成果

| 场景 | 实际产出与行为 | 仍需用户或研究者完成什么 |
| --- | --- | --- |
| G01 历史学，从没有论文开始 | 首轮只问导师方向；随后保存问题卡、组会短稿和选材便笺 | 选取可取得的报刊并真正阅读史料；未将候选问题当新发现 |
| G02 教育学，只有未经研究同意的闲聊 | 首轮只问方向；形成组会参与的候选问题和范围说明，保留笔记不能作研究证据的边界 | 与导师确认范围；正式收集资料仍需相应同意和程序 |
| G03 材料研究，只有不可读的项目占位文件 | 明确不能解析曲线；收到CSV后写中文结果；新对话发现T2端点由27变29，并区分旧稿和当前文件 | 提供合法可读导出，核对哪个数据版本正确；不能凭末端残余断言整体热稳定性或交联 |
| G04 自然表达与作者语气 | 完成26段表达练习，并检查语气、例外及科研限定 | 仍需作者审阅含义与风格，不作AI作者识别 |
| G05 直接编辑文件 | 更新指定草稿；实际词法检查未发现元数据、代码、链接、引用、公式和数字的保护片段变化 | 常见格式检查不是完整解析或科学语义证明；授权工作区内保留的保护副本不是额外交付 |
| G06 一条审稿回复 | 保留器件重叠、随机划分和单次新试验的限制，未把待做修改写成已完成 | 严格复评和真实改稿仍需完成 |
| G07 零散文献摘录 | 合并同一工作的版本，连起泛化与长期使用问题，保留负面结果和不可比条件 | 下一步仅用已有片段制作证据表，未声称读过全文或拥有论文中的数据 |
| G08 理论问题组会演练 | 一次一问；针对把三个例子当证明的回答反馈，并引导有效的反例检验 | 学生仍需自己推理；练习不算真实科研结论 |

## 提示、追问和操作

G01与G02从同一段朴素求助开始，不包含研究设计术语、输出模板或专家评分要求。两题首轮均只询问一个方向信息；用户用日常语言补充后，就有可供讨论的问题卡。研究材料不存在时，没有要求先准备十篇论文、填专业问卷或自行创建进度表。

三类项目均从真实检查点在全新上下文接续，未要求重述已经保存的学科与研究方向。最终检查点版本分别为4、4、7；文件、哈希、已答问题、待办与产物都有实际读回。用户没有被要求编写JSON、运行保存命令、复制模板或手工建立交接记录。这些操作由代理完成，并不表示模型没有执行命令。

历史学任务在接续时又问了一次尚未回答的城市或报刊线索，保留在原判记录中；这不是重问已知方向，也不是“完全没有追问”。材料任务则因CSV与旧稿不同，新增了版本核对问题。必要的材料导出、真实检索、访谈、实验、研究决策和安装步骤不能算作被技能免除的工作。

**本轮能证实的是任务能启动、产物确实保存、接续可用，以及未要求哪些手工操作。不能据此声称普遍少问几轮、固定节省多少分钟，或新手一定更喜欢它。** 阶段数预先固定，不能拿固定轮数当作提效结果；阅读量、学习负担与长期使用仍需要真人测试。

## 证据与复现边界

八类任务包含15次实际答复，使用11个执行上下文；其中三次接续没有前文聊天历史。五个独立判读任务逐项引用答复或明确标注的产物读回，不给总分。56项条件中54项判为通过、2项无法确认，没有判为不通过的项目；这些是条件核对，不是模型正确率或用户满意度。机器记录见 [引导与进度](results.json)、[表达与研究](expressions-results.json)及 [汇总](summary.json)。

G06和G08各有一项“未写文件”的条件，仅凭成稿正文无法确认，原判保留“无法确认”。另行从实际项目盘点读回的文件数均为0，未发现进度目录；这项工程证据与模型正文判读分开呈现，没有回改原判为通过。没有完整工具轨迹，不能证明所有未观察到的副作用。

开发过程中修正了测试封装的锁管理边界、永久协调记录实现、文献下一步的资源可得性约束和手工注释保护。初次运行及预览记录单独保留，不取优冒充最终执行。最终进度改动后重跑G01至G03；未受影响的G04至G08保留原始来源快照。两个报告分别选择三题和五题，索引要求合计覆盖全部八题；相关依赖改变仍需重测，不能更新旧哈希掩盖。

输入、检查项与来源快照固定于模型派发前。执行模型继承主会话，未设置模型覆盖；精确服务端版本与完整工具轨迹不可见。判读者为模型而非学科专家；每题只有一次最终执行，26段短练习也不等于26个独立用户。验证范围不涵盖所有学科、真实隐私资料、长期项目或期刊录用。
